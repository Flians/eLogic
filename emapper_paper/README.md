# eGraphMap / emapper paper

This directory is exclusively the eGraphMap technology-mapping paper.
The separate ePMapping post-mapping paper and talk remain in `../epmapping_paper/`.

- `DAC-eGraphMap-draft/main.tex`: paper source.
- `DAC-eGraphMap-draft/main.pdf`: compiled local draft.
- `../output/pdf/DAC-eGraphMap-draft.pdf`: released draft snapshot.
- `../data/CURRENT.md`: current evidence and limitations; the experimental V9
  profiles are not a completed full-EPFL study or an adopted final mapper.

The document target is at most6body pages plus1reference page, with compliant
fonts and margins. Source relocation does not change the paper claims or imply
that newer incomplete experiments have been inserted into its tables.

Existing local Overleaf Git metadata is retained separately; GitHub publication
tracks the actual paper source/assets, not an unregistered nested gitlink.
