## 代码与方法

1. **目标**：CLI 默认是 `area_delay_bound`。保存初始映射的全局延迟界限，面积优先，延迟打破面积平局。量化分辨率为面积 `1e-4`、延迟 `1e-3`，延迟容差 0.001 ps。非关键局部节点可以消耗 slack。整窗口综合被强制关闭。
2. **作用域**：先联合构造 AO21 两步链块并跨根复用，再逆拓扑访问根节点，执行结构 cut 替换。链事务按重建后的全局面积、延迟接受。
3. **候选**：L1 单单元、L2 数据库、L3 SOP/DSD 及 Shannon/正负 Davio；指定 MFFC cut 在前三类没有可接受结果时才进入 L4。每个分解家族保留两个支持规模排序的 pivot。
4. **e-graph**：饱和、提取不绑定本次叶到达时间。保存 DAG、内在面积和逐输入路径延迟向量，现场代入叶到达时间并重新估价。有限规则、8 个实现的前沿及工作预算构成不完整候选池，不能称为完整 Pareto 集或全局最优解。
5. **现场估价**：统一处理反相抵消与已有 live INV 复用。复用导致原可删除旧门继续存活时必须计价；已有共享门不重复计价。检查根依赖和环，再传播实际时序。
6. **接受与恢复**：局部 required time 过滤、净面积增量排序、替换后的缓存失效以及最终全网重建共同把关。严格检查点以独立规范网表保存；SIGALRM 仍是未完成搜索，恢复结果必须另有 CEC 与序列化 PPA 证据。

`epmapping/` 的算法/支撑头文件及 `main.cpp` 的核对口径以审计 JSON 的逐文件列表为准，均与 v28 冻结来源相同（列表共 8 个文件）。冻结的 211 项构建依赖中，207 项仍在原路径且字节相同；其余为 CMake/补丁应用脚本整理和两份补丁移动，当前 overlay 的四个已安装头文件保持原有实现。本次构建验证通过。

`operator_policy=3` 的统计性“延后/补检”在当前实现中立即完成，统计条件本身不会跳过结构构建。真正跳过现场估价的是严格非反相单元面积下界。不能把 mode 3 的统计计数解释成独立的已验证动态调度加速。

两组全部 704 个方法选择结果的原始参数、冻结输入、既有 CEC 记录、原生/序列化面积延迟边界均通过重新审计。原始返回码与检查点选择分别保留；没有把 7 次弱化控制的截止记为完成。主实验和 `full` 消融仍是独立运行，没有按电路拼接赢家。

mfs3 比较双方使用 byte-identical 初始网表和同一 ≤6 输入、40 项子库；主实验和消融使用完整 47 项库。mfs3 的面积模式不执行本方法的初始延迟约束；论文同时保留 raw 与外部 guard 的结果。双方 post-mapping 均限时 1000 s。共享主机、单次测量和冷/热协议限制了运行时间结论，不能宣称普遍快于 baseline。

## 后续优化优先级

- 优先减少 L4 冷启动饱和/提取的重复工作：当前完整消融去掉 L4 只损失累计 3.89 面积，但冷模式记录阶段时间中 L4 占约 49.4%。保持现场可行性复核，不扩大规则和前沿作为默认解决办法。
- 继续研究有明确结构依据的 pivot 预算。全 pivot 可多节省累计面积 36.93 / 39.99，但 mem_ctrl 冷热均 TO。先在固定输入上做有界预算实验，再决定是否采用，不能把统计收益当作安全剪枝证明。
- 保留查询复用：取消它使 div/sqrt 两组均截止，14 个完成配对 PPA 不变。真值表复用则约节省 2% 总时间。两项应按各自实际收益评价。
- 用有限的联合事务处理单根贪心覆盖不到的共享机会，保留严格全局面积/延迟 guard。当前仍有面积输给 mfs3 的电路，不能用总平均掩盖。
- 如需改变算法配置，另建实验目录重跑三部分，继续分开报告 cold/warm、正常完成/截止及实际质量，之后才更新论文数字。
