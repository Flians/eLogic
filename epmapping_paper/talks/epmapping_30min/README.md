# 工艺映射后的时序约束面积优化：30 分钟学术讲座

英文幻灯片、中文逐字讲稿，16:9、LaTeX Beamer。主讲 26 页，建议用时合计 30:00；附录 8 页，不计入主讲时间，也不包含答疑。

## 文件

- `epmapping_30min.tex`：入口、字体与版式。
- `frames.tex`：全部可编辑的幻灯片正文，主讲页内含 `\note{}` 讲稿。
- `speaker_notes.md`：逐页中文讲稿和累计时间，可直接照读，包含主讲及附录答疑段落。
- `timing.json`：26 页的秒级建议安排，总计 1800 秒。
- `assets/data.tex`：由核验后的实验记录导出的数值、表格与 PGFPlots 坐标。
- `assets/provenance.json`：数据文件 SHA-256 及实验约束。
- `build_data.py`：在原项目中刷新实验数值；日常编译不需要执行。

## 编译

需要 XeLaTeX、ctexbeamer、PGFPlots，以及 Noto Sans CJK SC 和 Noto Sans Mono CJK SC 字体。
在本目录运行：

```sh
make
```

生成 `epmapping_30min.pdf`。源码包自带冻结的数据，因此解压后不依赖原项目即可编译。
仅查看或修改讲稿无需重新运行实验。若需输出只含讲稿的可选 PDF：

```sh
make notes
```

## 实验口径

源数据为 `results_v28_three_parts_query_budget`，与当前 6+1 论文一致。主实验、直接映射对照、消融分别报告；原始输入不变，固定初始延迟界限，整窗口综合关闭，双方 post-mapping 限时 1000 秒。

- “128/128 无 TO”仅指完整配置在本批实验中的正常完成，不包括弱化控制，也不是理论复杂度保证。
- mfs3 配对平均值使用 ABC 正常完成的 13 电路；各工具以其原生初始成本归一化。3 个 ABC TO 和 7 个延迟违例均保留。
- 冷/热仅区分私有持久 profile 池；原生缓存重启，不清 OS 缓存。ABC 共享同一批经过验证的结果。
- 关闭查询加速的控制同时关闭 memo 与层级快速否定；关闭真值表复用仍保留公共标量 cut memo。
- 全 pivot 可以进一步减少面积，但两组均在 mem_ctrl 超时。消融输出差包含截止的影响。
- ASPDAC’25 数字仅按论文重建；起点不同，不能隔离后映射算法优势。

图中数据采用原生 LaTeX/PGFPlots，表格也是原生 LaTeX；可以修改配色、数值格式及布局。未使用占位作者、机构、虚构测量或外部装饰图片。
